Google setup — step by step
The app ships with no API key. You use your own — it's free.
1

Create a Google Cloud project

Go to console.cloud.google.com, sign in, and create a new project (e.g. MyVideos).

2

Enable the YouTube Data API v3

Left menu → APIs & Services → Library → search YouTube Data API v3 → Enable.

3

Create an API key

Credentials → + Create Credentials → API key. Copy the key shown.

4

Create an OAuth Client ID

+ Create Credentials → OAuth 2.0 Client ID → Type: Web application.
Add this exact redirect URI: http://localhost:5173/callback
Copy the Client ID shown.

5

Authorize your account

Google Auth Platform → Audience → Test users → add your Gmail address.

6

Enter your credentials in the app

On first launch the setup screen appears automatically. Paste your API Key and Client ID, click "Save and continue".

💡 Free and private. The YouTube API is free up to 10,000 requests/day (more than enough). All your data stays on your device — no third-party server involved.
